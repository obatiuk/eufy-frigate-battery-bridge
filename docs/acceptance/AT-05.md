# `AT-05`: `"rtsp"`, `"p2p"`, and `"auto"` Modes - Motion Wakes & External Stream Adoption

- On a camera configured with `mode: "rtsp"`, `mode: "p2p"`, or `mode: "auto"`:
  1. Configured Eufy trigger events (`motion`, `person`, `ring`, etc.), single-camera Frigate Live View, and
     `POST /api/wake/:cameras` must wake a live **`RTSP`** session (in `"rtsp"` or `RTSP`-capable `"auto"` mode) or
     **`P2P`** session (in `"p2p"` or non-`RTSP` `"auto"` mode).
  2. While `IDLE` (outside the `3s` post-sleep guard and when `!stoppingP2p`), external stream start events from
     `eufy-security-ws` must be adopted as an active live session (`initiator=eufy-ws`) matching the event protocol:
     `'rtsp livestream started'` (e.g., Home Assistant `button.*_start_rtsp_stream`) adopts live **`RTSP`** on cameras
     with `RTSP` enabled (`isRtspCapable()`), and `'livestream started'` (e.g., Eufy mobile app or
     `button.*_start_p2p_stream`) adopts live **`P2P`**.
