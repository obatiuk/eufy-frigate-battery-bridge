# `AT-17`: `POST /api/wake/:cameras`, Frigate Event Snapshots/Extensions, Auto-Masks & `ha_webhook_url`

- For external API wakes and Frigate/Home Assistant integration:
  1. `POST /api/wake/:cameras` must resolve `all`, camera `name`, `serial`, or slugified `title`, sort `RTSP` cameras
     before `P2P`, wake an `IDLE` `"backfill"` camera live when no Eufy trigger or `BackfillJob` is active (or stay in
     backfill mode and queue/upgrade the `BackfillJob` with `status: "backfill"` when a Eufy trigger, pending
     `BackfillJob`, or active `isBackfillPlayback()` is already in progress), pace live wakes on the same HomeBase by
     `2.5s`, coalesce duplicate bursts, and file a Frigate event unless `create_event: false`.
  2. Frigate events must wait for the first real video frame to reach Frigate (`~1s` live, `0.8s` backfill) or inject
     the clean cached snapshot (`suppressLiveCard`) if a wake times out without video, upgrade/extend when companion
     triggers or hold extensions exceed `evUntil`, auto-sync the status card polygon to Frigate's `motion.mask` and
     `objects.mask` when `auto_frigate_mask: true` (disabling masks for `card_theme: "none"` or centered modals), and
     send both initial and follow-up `ha_webhook_url` POSTs when configured.
