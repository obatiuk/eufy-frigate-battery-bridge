# `AT-06`: Per-Station `P2P` Arbitration vs. Parallel `RTSP` Independence

- On the same HomeBase (`stationSerial`):
  1. Multiple `RTSP` sessions (`STREAM_MODES.RTSP`) must run in parallel without blocking each other or blocking `P2P`
     backfill downloads (`usesP2pSlot() === false`), except that a `P2P` start waits briefly (`<= 5.5s`) while an `RTSP`
     camera on the same HomeBase is in its initial wake handshake (`WAKING_RTSP` before first frame).
  2. Only one `P2P` live session (`STREAM_MODES.P2P`) or in-transfer `P2P` backfill download (`STREAM_MODES.DOWNLOAD`
     while `!downloadFinished`) may hold the station's `P2P` channel at a time (`isOccupyingStationP2pChannel()`).
