# `AT-18`: 6-Color Status Palette, Debug HUD Service Statuses, Frame Pacing, Snapshot Isolation & `hwaccel` Fallback

- For status card overlays, encoder frame pacing, snapshot isolation, and media pipeline resilience:
  1. The bridge must support all 5 `card_theme` values (`"glance"`, `"minimal"`, `"pebbles"`, `"hud"`, `"none"`) across
     all 7 `card_position` placements (`"bottom-left"`, `"bottom-center"`, `"bottom-right"`, `"top-left"`,
     `"top-center"`, `"top-right"`, and `"center"`, including `"hud"`), throttle sleeping frames to `idle_fps`
     (`5 fps`) and active frames to `live_fps` (`15 fps`), and enforce the 6-color semantic status palette across all
     card themes without mutating `lastFrame`:
     - **White (`#ffffff`)**: `Asleep` and `Asleep (Low Battery)` (sleep-ready with all services healthy:
       `eufy-security-ws`, `HomeBase`/camera, `Frigate`, and `go2rtc` connected), as well as healthy unplugged battery
       (`> low_battery_threshold`, default `30%`), healthy Wi-Fi (`>= 2` bars), and normal temperature (`6..35°C`).
     - **Yellow (`#facc15`)**: `Waiting` (waiting for a station `P2P` slot, while `IDLE` with a pending `BackfillJob`,
       or during `HANDSHAKING_BACKFILL` before Frame 0 decodes), as well as unplugged low battery
       (`critical_battery_threshold < battery <= low_battery_threshold`, default `6..30%`), weak `1-bar` Wi-Fi
       (`<= -81 dBm`), and warm temperature (`36..44°C`).
     - **Purple (`#e879f9`)**: Unplugged critical battery (`<= critical_battery_threshold`, default `5%`, rendered in
       purple across `"minimal"`, `"glance"`, and `"pebbles"` themes, excluding `"hud"`) and hot temperature
       (`>= 45°C`).
     - **Blue (`#38bdf8`)**: `Waking Up...` (initial wake handshake before first video frame), as well as subtle
       sky-blue battery fill while charging (`Solar`, `Plugged`, or `Charging`).
     - **Red (`#ef4444`)**: `Live` (`L` / Play) or `Backfill` (`FB` -> `B` / Rewind).
     - **Grey (`#b4b4be`)**: `Disconnected` (whenever `eufy-security-ws`, `HomeBase`/camera, `Frigate`, or `go2rtc` is
       down/disconnected), as well as `Not available` for Battery, Wi-Fi, or Temperature icons/dots when a sensor value
       has not been reported (rendering a `15x15` top-right question mark `?` badge with a crystal cutout on the
       battery icon in `"glance"` and `"pebbles"` when battery percentage is unavailable).
       In `"hud"` theme (`buildDebugHudLines`), Row 1 Column 6 must display the 4 service statuses
       (`WS:OK HB:OK FRG:OK RTC:OK`, switching each to `DN` when down) directly above `HW:...`, and Row 3 Column 6 must
       display `TRIG:<STATE>  <SECS>  Q:<LIVE>/<DL>`.
  2. Snapshot cache files must be strictly isolated per camera (`last_<name>_<serial>.jpg`), must never read Eufy's
     `properties.picture` station-cached thumbnail, must hold the last decoded video frame (`frame || lastFrame`) during
     mid-session re-wakes and teardown once `gotVideo` is true so `"Waking Up..."` never flashes after video starts, and
     must run a `2s` startup snapshot probe only when a camera is online with `sleep_screen: "snapshot"` and no cached
     snapshot on disk (or `startup_snapshot: "always"`).
  3. The media pipeline must scale mid-stream resolution shifts (`360p` -> `1080p` / `2K`) in-band without restarting
     the `ffmpeg` decoder (restarting only on `H264 <-> H265` codec changes), pad non-`16:9` streams when
     `preserve_aspect_ratio: true`, and automatically fall back from GPU encoding (`hwaccel`) to software `libx264` on a
     camera if `ffmpeg` exits within `5s` of spawn with a hardware/driver error.
